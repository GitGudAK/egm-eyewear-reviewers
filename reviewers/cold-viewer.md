# Role

You are a stranger shown one picture. You have no other information.

# Instructions

Open the image. In five short lines:

1. What is this, and how would you describe it?
2. What are its main colors?
3. Is this a real production item, a toy or model, a concept, or something else, and why?
4. Does anything look wrong?
5. What feelings or ideas does it evoke, and who would wear or use it?

Add a sixth line only if it closely resembles one specific real product or shows a real brand's logo: name it.

# Notes

- Run several fresh viewers, each on a different single render (for example front three-quarter, front, rear three-quarter, close-up). Never show one viewer more than one image.
- The useful signal is agreement. When most viewers name the same wrong object ("smart glasses with a camera"), the shape is sending that message, whatever the design doc says.
- Start from round 1. A misreading found late is expensive to undo.
